# 砚台 · 人设馆

SillyTavern 原生人设管理与人设助手扩展。它直接读取酒馆已有的人设、头像、默认人设、存档绑定和角色卡绑定，不要求用户重新搬运人设。

## 安装

在酒馆中打开 **扩展 → 安装扩展**，粘贴：

```text
https://github.com/ayan-atelier/yantai-persona-studio
```

分支和标签留空，选择“只给我安装”，安装后刷新酒馆。也可以下载本仓库文件，把整个目录放进酒馆的第三方扩展目录。

### 更新说明

当前稳定正式版是 **`v1.1.2`**，全员统一使用 **`main` 主线**更新（已支持酒馆自动更新与「管理扩展」一键更新）：

- 若你此前曾通过旧版插件内的“版本切换”停留在 `v1.0.x` 等旧分支上，只需在酒馆 **「扩展 → 管理扩展」** 的分支下拉框中选回 **`main`**（或点更新），即可恢复跟主线同步。
- `v1.1.2 / v1.1.1` 根治了 TauriTavern (TT) 下偶发刷不出人设馆或面板空白的启动阻塞与抽屉动画竞态，同时包含 `v1.1.0` 的 Milo 流式纯净生成、候选人设一键导入酒馆、多端静默无损自动合并以及三重防丢人设保护。

### 跨设备同步

直接更新这个扩展即可使用兼容同步。人设馆只读写自己的 `extensionSettings` 命名空间，并调用酒馆已有的设置保存入口；不需要额外复制插件。分组、图库清单、人设助手记录和草稿会随同一个酒馆实例的设置保存，页面选项仍保留在当前设备。兼容模式会在保存前合并现有记录，但酒馆原生设置没有并发版本校验；经常同时在多台设备编辑时，再启用下面的服务端增强。

如果需要更强的并发保护，可以额外启用仓库里的 `server-plugin/yantai-persona-sync`：把整个目录复制到酒馆根目录的 `plugins/yantai-persona-sync`，在 `config.yaml` 打开 `enableServerPlugins: true`，然后重启酒馆。服务端模式把同步数据保存到独立文件，写入带版本校验、备份和冲突留档。普通安装不需要这一步；服务端插件属于可选增强。

## 功能

- 接管酒馆原生人设入口，提供当前人设、档案和新建／编辑页面；“新建空白人设”调用酒馆原生创建流程，不复制已有条目。
- 人设档案支持设为当前、编辑、复制和删除；删除沿用酒馆原生确认。
- 人设档案支持分组管理：没有自定义分组的人设显示为“默认”，可新建分组、筛选并把每份人设移动到对应分组。
- 编辑页支持头像、备注、描述、世界书和四种常用归属。
- 头像图库与角色卡图库分开，头像上传沿用酒馆原生裁切；图库从人设馆工作区进入。导入图片的查看原图和删除按钮分别排列，预览正常时也可以删除素材。
- 图库图片会通过酒馆原生图片图库接口保存到服务器的 `user/images`，不会进入人设头像目录，也不会自动创建人设；设置里只保留轻量清单，同一酒馆地址下的手机和电脑可共享素材，IndexedDB 继续作为本机离线缓存。服务器拒绝上传时只保留本机副本，不会清空已有图片。
- 扩展设置里可以随时关闭人设馆接管，恢复酒馆原生人设界面；开启、关闭不会删除人设或图库文件。
- 支持从扩展设置主动检查版本、更新到最新版或退回上一兼容版本。切换前会备份人设馆设置，酒馆原生资料与图库文件保持不变。
- Milo 人设助手接入酒馆当前主 API，首次给两条可玩的 User 人设方向，后续可继续对话。
- 助手记录使用全局 `milo-global` 线程，角色卡摘要和存档片段只作为本轮可选资料；跨设备保存时会合并旧卡片线程并去重，API 每次只发送最近十轮压缩记忆，界面保留完整回复。
- 助手会完整保留与问题有关的 `reply`；候选人设保留独立正文，便于复制使用。
- 原卡资料只作为片场制作资料，候选可以调整职业、住处和关系网，避免整套身份直接暴露原卡。

## 数据与兼容

酒馆原生人设、默认人设和存档／角色卡绑定仍由酒馆的 `settings.json` 管理；专用同步只保护人设馆自己的分组、图库清单、助手记录和草稿。跨设备使用原生人设前，先确认酒馆本身的设置同步或快照已经完成。图库图片本体保存在酒馆服务器的 `user/images`，IndexedDB 只作为当前设备的离线缓存。旧版本曾放进 `User Avatars` 的图库图片会在保存时迁移，避免被酒馆误认成人设。

颜色和尺寸跟随当前酒馆主题变量，手机和电脑使用同一个入口。当前开发版已在 SillyTavern 1.19.0 本地桌面端和移动浏览器环境做过基础回归，其他主题、TauriTavern 版本仍建议先小范围测试。

## 版本

当前正式版：`1.1.2`（统一 `main` 主线自动更新）。

- **稳定正式版，推荐手机（含 TauriTavern / TT）和电脑都使用这一版。**
- 统一为单 `main` 主线发布并开启 `auto_update: true`，支持酒馆原生「管理扩展」一键更新与自动切回主线。
- 专项修复 TauriTavern (TT) 偶发刷不出来与抽屉空白问题：改为静态模块并行预加载、第 1 帧瞬时挂载工作区、IndexedDB 与 Tauri IPC 请求硬超时兜底、切卡瞬间防丢帧自动补刷，以及覆盖 200ms 抽屉切换动画的阶梯巡检。
- Milo 人设助手改用独立纯净流式请求（绕开主预设污染、SSE 实时逐字输出、断流自动抢救、多轮自适应交付候选正稿）。
- 候选人设卡片支持「一键导入酒馆并启用」与「仅存入档案」，无需手动复制粘贴。
- 跨设备同步支持后台静默无损自动合并（Auto-Rebase），手机和电脑来回切换不再弹出黄色冲突或副本未合并警告，同时具备防覆盖、防诈尸与 `[Unnamed Persona]` 快照自愈三重保护。
- 确认同步前先上传图库原图，上传失败时保留本机副本，不把文件名元数据写成另一台设备的空卡片。
- 启动时静默处理可恢复的同步状态，旧的无地址图库记录不会继续显示成空卡片。
- 修复图库拖拽 JPG 时事件冒泡到酒馆全局角色卡导入器而产生“不支持的文件类型”提示。
- 保存人设后刷新酒馆原生编辑区和人设列表，避免原生文本框残留旧描述。
- 修复进入角色卡或存档时，人设助手因酒馆上下文短暂切换而不显示回复的问题。
- 兼容角色卡加载期间的临时标识与正式标识，避免回复落到隐藏的临时线程。
- 保留 `v1.0.7` 的常见回复字段解析、普通文本回退和失败重试兼容。
- 助手历史统一使用 `milo-global`，旧卡片线程首次打开时自动合并并去重；清空记录使用墓碑标记，避免旧设备把记录重新写回来。
- 修复普通安装下删除图库图片后被旧同步清单重新恢复的问题；重新导入同一素材会清除旧远程地址并重新上传。
- 修复上传或删除后酒馆兼容保存导致全部缩略图消失的问题；保存后会恢复本机预览，并回退到服务器图片地址。
- 修复人设助手发送后手机端看不到回复的问题；助手记录保存不再等待图库迁移。
- 手机和电脑使用共享助手线程，旧设备记录会在首次打开时自动合并；世界书仅在勾选后读取。
- 修复跨设备图库图片无法裁切应用的问题；没有本机缓存时会从酒馆服务器取回原图，并且只覆盖已有的人设。
- 编辑页移除重复的顶部说明，减少手机端滚动距离；新建页明确提示点击“创建人设”保存。
- 修复人设档案编辑、设为当前和删除操作的状态同步与错误反馈。
- 编辑页保存按钮靠近名称，原生编辑移到绑定区，删除集中在档案页。
- Milo 页面改为紧凑聊天布局，资料横排，回复长度受控，保留最近十轮记忆。
- 缩小 DOM 监听范围，避免全页面属性变化触发重复同步。
