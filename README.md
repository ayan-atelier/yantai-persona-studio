# 砚台 · 人设馆

SillyTavern 原生人设管理与人设助手扩展。它直接读取酒馆已有的人设、头像、默认人设、存档绑定和角色卡绑定，不要求用户重新搬运人设。

## 安装

在酒馆中打开 **扩展 → 安装扩展**，粘贴：

```text
https://github.com/ayan-atelier/yantai-persona-studio
```

分支和标签留空，选择“只给我安装”，安装后刷新酒馆。也可以下载本仓库文件，把整个目录放进酒馆的第三方扩展目录。

## 功能

- 接管酒馆原生人设入口，提供当前人设、档案和新建／编辑页面。
- 人设档案支持设为当前、编辑、复制和删除；删除沿用酒馆原生确认。
- 编辑页支持头像、备注、描述、世界书和四种常用归属。
- 头像图库与角色卡图库分开，头像上传沿用酒馆原生裁切。
- Milo 人设助手接入酒馆当前主 API，首次给两条可玩的 User 人设方向，后续可继续对话。
- 助手按用户、角色卡、存档和会话隔离记录，API 每次只发送最近十轮压缩记忆。
- 助手 `reply` 每轮最多 1000 字；候选人设保留独立正文，便于复制使用。
- 原卡资料只作为片场制作资料，候选可以调整职业、住处和关系网，避免整套身份直接暴露原卡。

## 数据与兼容

酒馆原生人设仍是唯一数据源。扩展自己的设置主要是图库附加文件、助手记录和草稿；头像素材保存在当前浏览器的 IndexedDB 中。

颜色和尺寸跟随当前酒馆主题变量，手机和电脑使用同一个入口。当前开发版已在 SillyTavern 1.19.0 本地桌面端和移动浏览器环境做过基础回归，其他主题、TauriTavern 版本仍建议先小范围测试。
